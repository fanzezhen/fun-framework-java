# 本项目（fun-framework-java）专属规范

仅适用于本框架项目本身，使用本框架的子项目不受此约束。

## 框架能力查询

本框架项目本身涉及通用功能（统一返回、分页、全局异常、参数校验、对象转换、MyBatis-Plus、跨域/拦截器/过滤器、Redis/ES/Sa-Token/Sentinel 集成、SpringDoc、Jasypt 等）前必须读 `专业提示词/java脚手架.md`（本地 `doc/dev/提示词/专业提示词/java脚手架.md` → GitHub Raw → Gitee Raw），完整场景与用法以该文档为准。业务 Controller/Service/Mapper、启动类、非框架集成的配置类无需查阅。

## 文档维护规则

本项目属脚手架（组件/框架类）项目，文档维护读 `专业提示词/文档维护-组件类.md`，不读业务类。

- 任何改动后同步所改模块 README 与根 README
- 触发范围、就近原则、更新方式与自查清单以该文档为准

## 文档版本号管理

禁止在文档中硬编码版本号（适用于 README、提示词、注释等）。

- 错误："基于 Spring Boot 4.0.5"、"Java 21"、"v5.0.0"
- 正确："基于 Spring Boot 最新稳定版本"、"查看 pom.xml 获取当前版本"

允许硬编码版本号的位置：
- `pom.xml` 依赖声明
- git commit message
- CHANGELOG.md（如存在）

推荐表达：
| 场景 | 表达 |
|------|------|
| 技术栈 | "基于 Spring Boot、Java、MyBatis Plus 最新稳定版本" |
| 版本查询 | "查看 pom.xml 获取当前依赖版本" |
| 依赖管理 | "依赖版本由框架父 POM 统一管理" |

## 开源项目迭代

- 持续升级到最新稳定版
- 版本号在父 POM 统一声明
- 子模块禁止覆盖父 POM 的版本号
- 文档中无硬编码版本号，无需随升级更新
