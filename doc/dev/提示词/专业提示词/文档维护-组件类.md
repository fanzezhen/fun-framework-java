# 文档维护（组件类）

面向组件/框架类项目。与全局提示词配合使用，专管改动后的 README 同步。

## 核心规则

任何改动后，必须同步更新两处 README：

1. 所改模块的 README.md
2. 项目根 README.md

改动即触发，缺一不可。模块 README 记录该模块自身的能力/用法变化；根 README 记录跨模块视角的模块清单、能力索引、结构变化。

## 触发范围

需更新 README：
- 新增/删除/重命名模块
- 新增/变更/移除对外能力（API、配置项、starter、自动装配、扩展点）
- 依赖坐标（groupId/artifactId）或引入方式变化
- 用法/示例变化

无需更新 README：
- 内部实现优化、重构（对外行为不变）
- 测试、格式、注释
- 用法不变的版本升级（README 不硬编码版本号）

## 就近原则

- 改动落在哪个模块，就更新哪个模块的 README；跨多模块则逐个更新
- 存在中间层聚合 README（模块组根）时，若其列出了子模块清单或能力索引，一并更新
- 层级：子模块 README → 模块组 README（如有）→ 根 README，自下而上核对

## 更新方式

- 按原文档结构就地重整，不只在末尾追加
- README 不硬编码版本号，用"最新稳定版""查看构建文件获取版本"等表述
- 框架能力变化时，同步项目的能力索引文档（如有，见全局提示词"脚手架查询"）；无则跳过

## 完成前自查

- [ ] 所改模块 README 已更新
- [ ] 根 README 已更新
- [ ] 中间层聚合 README（如有）已核对
- [ ] 无硬编码版本号
- [ ] 涉及框架能力索引变化时已同步对应索引文档（如有）
