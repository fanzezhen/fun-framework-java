# 前端补充规范

与全局提示词配合使用。

## 默认技术栈

用户未指定时使用：
- 框架：Vue 3（`<script setup>`）或 React 18（函数组件 + Hooks）
- 构建：Vite（优先）或 Webpack 5
- UI 库：Vue → Ant Design Vue / Element Plus；React → Ant Design / MUI
- HTTP：Axios（假设已封装拦截器）
- 不引入过重或不必要的第三方依赖

## 组件规范

### 组件内逻辑顺序
1. `props` / `emits`
2. 响应式状态（`ref`/`reactive`/`useState`）
3. 计算属性（`computed`/`useMemo`）
4. 方法
5. 生命周期（`onMounted`/`useEffect`）

### 异步处理
- 必须处理 `loading` 和 `error` 状态
- 提供加载动画/错误提示

### 样式
- Vue 用 `<style scoped>`，React 用 CSS Modules
- 优先 Flexbox/Grid，避免 `position: absolute` 硬编码

## 与后端协作

### 接口调用封装
- 所有接口封装在 `api/*.js` 或 `services/*.ts`
- 禁止组件内直接 `axios.post`

### 统一响应格式（fun-framework-java）

后端使用本框架时返回结构：
```typescript
interface ApiResponse<T> {
  code: number;      // 200=成功
  message: string;
  data: T;
}
```

Axios 拦截器统一处理：
```typescript
axios.interceptors.response.use(
  (response) => {
    const { code, message, data } = response.data;
    if (code === 200) return data;
    Message.error(message || '请求失败');
    return Promise.reject(new Error(message));
  },
  (error) => {
    Message.error('网络请求失败');
    return Promise.reject(error);
  }
);
```

### 数据格式
- 日期时间：ISO 8601（`yyyy-MM-dd'T'HH:mm:ss`），前端格式化展示
- 枚举：定义常量映射对象，避免模板硬编码

## 三层穿梭典型问题

| 问题 | 本质 | 方案 |
|------|------|------|
| 异步执行顺序错乱 | 异步控制流、错误边界、时序依赖 | `Promise.all` 并行、状态机管理 |
| 组件间数据不同步 / Props drilling | 缺少单一数据源、状态提升不当 | Context/Provide-Inject、Pinia/Vuex/Zustand |
| 渲染卡顿 / 频繁重渲染 | 不必要重渲染、大列表无虚拟化、计算未缓存 | `React.memo`/`useMemo`/Vue `computed`、虚拟滚动、代码分割、懒加载 |
